# customIcons

Sophisicated Windows 10/11 icon changer.

![image](https://user-images.githubusercontent.com/86447165/224623882-e0e553c1-78ac-4598-8a4e-b4d620853dec.png)

## Features
Patch icons of Folders and Drives
Change Desktop Icons   
Save DLL/EXE/MUN icons as PNG or ICO, or copy it to your clipboard   
Icon Packs that you can import
Search icons in a pack
and, much, much more!

> Regarding the portable version, if the app does not open check the [FAQ section for customWin](https://surfscape.eu/support/#customwin) in the SurfScape website.
